# 창덕궁 — 원본 실측 사실

국가유산청(KHS) 공식 3D 스캔 17건으로 인정전·구선원전 권역을 짓는 작업의 측정 기록.
추정이 아니라 전부 Blender에서 프로브해서 얻은 값이다.

## 규모

- 17개 에셋 = **25,466,722 트라이앵글 / 508 머티리얼**
- 인정전 하나가 **10.42 M (41%)**. 다음이 외행각 2.60 M, 선원전 2.01 M
- 품질 목표: 약 1.2 M 트라이앵글 (약 1/20으로 감축)

## 원본을 다룰 때 알아야 할 것

- **FBX 파일 크기는 폴리곤 수의 지표가 아니다.** 대부분이 임베드 텍스처다
  (북진설청: 164 MB 중 155 MB가 텍스처). `PolygonVertexIndex`를 파싱해서 세라.
- **텍스처는 건물 간 바이트 단위로 동일하게 중복된다.** 1,011 인스턴스 → **고유 304개 (1.64 GB)**.
  같은 파일명이 서로 다른 CRC를 갖는 경우는 하나도 없었으므로, 파일명 키 라이브러리가 안전하고
  **3.3 GB를 절약**한다.
- **각 FBX는 Geometry 노드 1개** — N개 머티리얼 슬롯을 가진 통짜 메시다.
  그래서 첫 작업은 무조건 머티리얼별 분할이다.
- **에셋들은 서로 정합되어 있지 않다.** 각자 자기 로컬 원점에 있고 지면 Z도 제각각이다
  (인정전 −11.6 m … 내재실 +0.65 m). 에셋 간 bbox 중심 거리는 3–24 m인데 실제 OSM 거리는
  15–212 m다. **배치는 별도로 풀어야 한다** — OSM 발자국을 앵커로 썼다.
- 508개 머티리얼 전부 Base Color가 이미지 텍스처에 직결되어 있다. 노드 체인 0개.
- Blender 5.2는 1.17 GB짜리 인정전을 18초에 임포트한다. 스트리밍 리더 같은 우회는 불필요.

## 감축 정책

구조체(기둥·보·석축)는 **평면 병합만** 적용한다. 지붕 곡면과 단청 디테일에 데시메이트를 걸면
처마 실루엣이 무너진다. 재질별로 정책을 다르게 가져가는 것이 핵심이다.
