# JSN_Sangok 미사용 지형 에셋 조사

조사일: 2026-08-14  
범위: `국가유산_3D_건조물/지형` 아래 239개 ZIP과 카탈로그 243개 항목. ZIP을 풀지 않고 중앙 디렉터리, FBX 배열 헤더, OBJ 스트림, 이미지 헤더를 직접 검사했다.

## 결론

- 현재 산곡 맵에 추가 가치가 가장 높은 미사용 에셋은 **무등산 주상절리대 전체본**이다. 다만 약 180만 삼각형으로 추정되는 거대 단일 메시라 원본 그대로는 게임용이 아니다. 원경의 영웅 암벽이나 실루엣 참조로만 쓰고 강한 감량·재토폴로지가 필요하다.
- 다랑이논은 규모가 현재 맵과 비슷하지만 약 399만 삼각형의 농경 경관 전체 스캔이다. 자연 산곡 본체에 합치기보다 별도 농촌 맵 또는 지형 형태 참조에 적합하다.
- 오륙도와 산방산은 해안·제주 화산 지형이라 내륙 조선 산곡의 지질과 경관에 맞지 않는다.
- 세립사·중립사·조립사 15건은 **0바이트 손상본이 아니다.** 파일은 열리고 간단한 메시도 들어 있다. 다만 1×1 단색 텍스처와 약 180개 삼각형뿐인 초저정보 샘플이라, 실질적인 자연지형 재료로는 가치가 낮다.

## 세립사·중립사·조립사 15건 검증

구성은 세립사 1~5, 중립사 1~5, 조립사 1~5로 총 15건이다.

| 항목 | 실제 검사값 |
|---|---:|
| ZIP 크기 | 15,460~15,747 bytes |
| ZIP 내부 파일 | FBX 1개 + PNG 1개 |
| FBX 크기 | 50,144~50,256 bytes |
| 정점 좌표 배열 | 276 doubles = 92 vertices |
| 폴리곤 인덱스 배열 | 540 indices ≈ 180 triangles |
| PNG | 90 bytes, 1×1 단색 |

판정: 다운로드 실패나 0바이트 손상은 아니다. 이름별 다섯 색상 샘플을 담은 매우 단순한 지면 조각으로 보인다. 고주파 모래 디테일, 노멀, 러프니스가 없으므로 산길·계류 하상 재료로 가져올 이유가 없다. 현재 사용 중인 SSW/CDG PBR 조합이 우수하다.

## 무등산 주상절리대 전체본

파일: `천연기념물_무등산_주상절리대_원본.zip`

| 항목 | 실제 검사값 |
|---|---:|
| ZIP | 197,049,219 bytes |
| FBX | `SM_MDS_Entire.fbx`, 93,671,360 bytes, FBX 7700 |
| 정점 좌표 배열 | 2,700,465 doubles = 900,155 vertices |
| 폴리곤 인덱스 | 5,391,444개, 삼각 메시라면 약 1,797,148 tris |
| Base Color | 4096² RGB, 평균 약 (100.5, 91.0, 87.5) |
| Normal | 4096² RGB |
| Roughness | 4096² grayscale |

현재 `_extracted/ROCK_ColumnarMass`에도 같은 전체본이 추출되어 있다. A~F 모듈보다 실루엣 연결성이 좋아 원경 암벽에는 유리하지만, 다음 이유로 현재 플레이 공간에는 바로 넣지 않는다.

1. OVERDARE의 30k tris/메시 기준을 약 60배 초과한다.
2. 기존 A~F와 중복되는 무등산 지질·텍스처라 장면 다양성보다 비용 증가가 크다.
3. 전체 스캔의 바닥·경계가 현재 해석적 지형과 맞지 않아 매립과 재토폴로지가 필요하다.

권장 사용법: 원경 전용 2~4개 청크로 자르고, 실루엣 보존형 감량 후 10~30k tris/청크로 만든다. 근거리에는 현재 A~F 모듈을 유지한다.

## 자연유산 3건 실제 내용물

세 건 모두 `OBJ + MTL + 8192² JPG 1장` 구조다. 노멀·러프니스·AO 등 PBR 맵은 없다. OBJ 좌표 단위를 미터로 보는 것은 파일 규모에 근거한 추정이며 메타데이터로 확정된 값은 아니다.

| 에셋 | 정점 | 삼각면 | OBJ 좌표 크기 X×Y×Z | 판정 |
|---|---:|---:|---:|---|
| 남해 가천마을 다랑이논 | 1,999,081 | 3,988,094 | 137.73×128.90×47.46 | 크기는 맵과 유사하나 농경지 전체 스캔. 별도 농촌 맵/형태 참조 후보 |
| 부산 오륙도 | 1,015,201 | 2,029,288 | 652.48×1,313.19×77.63 | 해안 섬 실루엣. 내륙 산곡에는 부적합 |
| 제주 서귀포 산방산 | 2,004,734 | 4,000,000 | 2,036.09×2,237.18×420.18 | 거대 제주 화산체. 지질·스케일 모두 현재 맵과 부적합 |

세 메시 모두 원본 그대로는 30k tris/메시 규칙을 크게 초과한다. 단일 JPG 투영이라 분할·감량 후에도 텍스처 해상도와 UV 경계 관리가 필요하다.

## 적용 우선순위

1. 현재 빌드에서는 추가 대용량 원본을 넣지 않는다.
2. 원경 실루엣이 더 필요할 때만 무등산 전체본을 별도 저폴리 청크로 시험한다.
3. 너덜지대 다양화가 필요하면 빌레못동굴 낙반 1개를 먼저 샘플 검사한 뒤, 색 보정과 강한 감량이 가능한 경우에만 채택한다.
4. 다랑이논·오륙도·산방산은 현재 산곡 맵 조립 대상에서 제외한다.
