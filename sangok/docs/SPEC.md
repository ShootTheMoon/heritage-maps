## 1. 개요

국가유산청(KHS) 3D 스캔으로 조립한 **조선 시대 내륙 산곡 자연지형 게임 맵**.
최종 타깃 **OVERDARE**(Roblox 계열 Luau/Unreal UGC 플랫폼) FBX.

| | |
|---|---|
| 맵 크기 | 260 × 260 m |
| 표고차 | 82 m |
| 플레이 가능 범위 | \|x\|,\|y\| ≤ 105 m (약 210 × 210 m) |
| 코어 플레이 | 약 190 × 200 m |
| 단위 | **1 BU = 1 m** |
| Blender | 5.2.0 LTS, 렌더 엔진 `BLENDER_EEVEE` (레이트레이싱 ON) |
| 씬 규모 | 2,450 오브젝트 / 44.0 M tris / 유니크 메시 15 / 머티리얼 18 |
| 마스터 | `00_Source_Blender/JSN_Master.blend` 130.2 MB |

**설계 원칙**: 지형은 해석적 높이함수 `height_at(x, y)`로 저작하고, KHS 스캔은
그 위에 얹는 드레싱으로 쓴다. 모든 배치가 `height_at`을 참조하므로 **지형을 고치면
나무·바위·자갈·수면이 자동으로 따라온다.** 배치는 결정적 해시라 재실행해도 동일하다.

## 2. 지형 구조

```
        북(+Y)  ── 고갯길 안부(초크) y≈96, 그 앞 깔딱고개 y 69~81
          ▲          └ 석단(디딤돌 6개) y 76.0~79.6
          │
  서(-X)  │  동(+X)
  주상절리 │  완만한 소나무 사면
  암반능선 │  (공터 3곳)
  x≈-78   │
  너덜     │  ← 계류(溪流) x≈stream_x(y), 남북 관류
  x≈-46   │  ← 산길 x≈trail_x(y), 계류 동안
          │
        남(-Y)  ── 진입로 y≈-95
```

- **계류**: `stream_x(y)` 사행. 종단 범위 y −96 ~ +90 (`stream_len`). 도랑 폭 2.9 m /
  깊이 1.7 m. 남쪽으로 흐른다(북 z≈8.9 → 남 z≈−1.2).
- **지류**: x −66 → +7에서 발원해 y≈−16에서 본류 합류. 깊이 2.1 m / 폭 2.6 m.
  산길과 만나는 곳이 **도섭(徒涉) 지점**.
- **산길**: `trail_x(y)`. 가시폭 약 1.4 m. 조선 산골 소로(嶺路) 기준.
- **외곽 산벽**: r > 100 m에서 30·t² 융기. 투명벽 없이 맵을 자연스럽게 닫는다.
- **스커트**: 격자 경계를 −55 m로 extrude. 바깥 시점에서 판 절단면이 안 보이게.

### 전술 의도 (주의: 아래 3절 참조)

골짜기 바닥 = 저지 우회로 / 양쪽 능선 = 고지 / 북쪽 안부 = 초크 /
서쪽 너덜 = 엄폐물 / 지류 협곡 = 이동 차단선.

## 3. **알려진 최대 이슈 — 지형이 이동을 제약하지 않는다**

`walkability.md` 참조. 두 차례 측정 결과:

| | |
|---|---|
| 판정 | PASS (연결성분 1개 = 96.8%, 고립 구역 0, 주요 지점 8/8 연결) |
| 보행 가능(≤40°) | 89.5% |
| 기어오름(40~55°) | 7.3% |
| 경사로 인한 통행 불가(>55°) | **0.0%** |
| 암반으로 인한 통행 불가 | 3.2% |
| 60° 초과 지형 | **한 셀도 없음** |

**2절의 전술 구조는 시각적으로만 성립하고 실제로는 아무 데나 걸어서 갈 수 있다.**
서쪽 "암반 능선" 마루 경사가 6.7°로 능선이 아니라 둔덕이고, 지류 협곡 2.1 m는
그냥 건너진다. 실제 이동 제약은 배치한 암반 프롭 3.2%뿐이다.

고치려면(**사용자 승인 필요 — 플레이 설계 변경**):

1. 서쪽 능선 마루를 좁히고 동사면을 55° 이상으로 세워 정상 접근로를 2~3곳으로 한정
2. 북쪽 안부 좌우 능선을 +8~10 m 올려 안부를 진짜 통로로
3. 지류를 국부적으로 3.5 m / 50° 이상으로 파고 건널목을 1~2곳으로 한정
4. 너덜은 현재가 적절 — 유일하게 작동하는 제약

이 작업은 성격을 "자연스러운 산곡"에서 "게임적으로 조형된 산곡"으로 이동시킨다.

## 5. 코드 구조 — `_scripts/jsn_live.py` (약 1,400행)

Blender MCP 또는 Blender 내부에서 **함수 단위로 호출**한다. 애드온 아님.

```python
import importlib.util, sys
spec = importlib.util.spec_from_file_location(
    "jsn_live", r"<PROJECT>/_scripts/jsn_live.py")
m = importlib.util.module_from_spec(spec); sys.modules["jsn_live"] = m
spec.loader.exec_module(m)

m.stage1()          # 지형 + 계류 + 지류 + 석단 + 조명 + 카메라
m.stage2()          # 에셋 임포트 + 배치(암반/소나무/하층/자갈/암괴)
m.export_manifest() # 05_Documentation/scene_manifest.json
m.save()            # 00_Source_Blender/JSN_Master.blend
m.render(cams=("Survey","Valley","Ridge","Pass"), tag="s34")
m.walkthrough()     # 눈높이 9컷
m.walkability()     # 보행성 감사 -> walkability.json / _grid.json
```

빈 씬에서 `stage1()` → `stage2()`면 **전부 재생성**된다. blend는 산출물이지 원본이 아니다.

### 핵심 함수

| 함수 | 역할 |
|---|---|
| `height_at(x,y)` | 지형 높이. 골짜기 단면 + 종단 상승 + 서/동 능선 + 안부 절개 + 깔딱고개 융기 + 계류 도랑 + 지류 협곡 + 산길 노반 + 미세 기복 + 외곽 산벽 |
| `blend_at(x,y)` | 정점컬러 `Blend` (R=마사토/솔가리, G=암반, B=젖은 하상) |
| `stream_x/stream_len/trib_y/trib_amt/trail_x` | 계류·지류·산길 중심선과 종단 범위 |
| `talus_amt(x,y)` | 서쪽 너덜 강도. y≈8.6 최대, 주기 114 m |
| `pine_density(x,y)` | 소나무 밀도. 경사·크레스트·너덜·동사면 공터 반영 |
| `_h01(i,j,salt)` | 결정적 해시. **난수 시드 의존 없음 → 재실행 재현성** |

### 좌표·경로

- `ROOT` = 프로젝트 폴더(스크립트 위치의 상위). **절대경로 하드코딩 없음.**
- `_TexLib/`에 지면·석재 텍스처 12장(147.9 MB)을 동봉. 있으면 그걸 쓰고,
  없으면 원래 CDG/SSW 경로로 폴백한다(`_HAVE_LOCAL`).

## 9. 다른 PC에서 시작하기

1. 압축 해제. 경로 제약 없음(스크립트가 자기 위치에서 `ROOT`를 잡는다).
2. Blender **5.2 이상**으로 `00_Source_Blender/JSN_Master.blend` 열기.
   텍스처는 `_TexLib/`·`_extracted/` 상대 참조라 그대로 보인다.
3. 다시 만들려면 빈 씬에서 5절의 호출 순서를 실행.
4. `jsn_live.py`는 **한 사람만 편집**한다(3자 협업 중 충돌 방지 규칙).

### 뷰포트 주의

- `shading.type='RENDERED'`는 대형 씬에서 GPU 드라이버를 죽인 전례가 있다
  (CDG 프로젝트, `nvoglv64.dll` ACCESS_VIOLATION). **MATERIAL 프리뷰**를 쓸 것.
- `SOLID + TEXTURE`는 지형이 흰색으로 나온다. 지형에 UV가 없고 Object 좌표
  BOX 투영을 쓰기 때문이며 버그가 아니다.
- 텍스처를 **절대 pack 하지 말 것.** CDG에서 `pack_all`이 8.83 GB를 만들어
  드라이브를 채우고 저장이 조용히 실패한 전례가 있다.

## 10. 이 프로젝트에서 실제로 깨진 것들

전문은 `README.md`(함정 18가지). 재발 방지 핵심만:

1. **`Generated` 좌표 금지** — 표고차 82 m 지형에서 급경사면이 세로로 늘어난다.
   `Object` 좌표 + `projection='BOX'`.
2. **머티리얼 배선 함수는 오브젝트가 아니라 머티리얼을 받아야 한다** — 오브젝트를
   받아 모든 슬롯을 돌면 마지막 호출이 앞을 덮어써 곰솔 수피가 한 번도 안 쓰였다.
3. **부위 판별을 머티리얼 이름으로 하지 말 것** — 3ds Max 출력이라 이름이
   `Standardmaterial_7/_8/_9`뿐이다(7=줄기 8=잎 9=이삭).
4. **격자 해상도가 표현 가능한 지형 특징 폭을 결정한다** — 폭 1.9 m 도랑을 1 m
   격자에 파면 벽이 톱니로 갈라진다.
5. **지형 특징을 맵 끝까지 끌고 가지 말 것** — 계류가 외곽 산벽을 타고 z=+17 m까지
   올라가 검은 수직 벽이 됐다.
6. **bmesh 절차적 메시엔 UV가 없다** — 이미지 텍스처를 그냥 연결하면 새까맣다.
7. **EEVEE `use_raytracing`을 켜야 물이 물로 보인다.**
8. **지형 특징은 종단면을 수치로 찍어 확인할 것** — 고갯길이 안부로 '내려가는'
