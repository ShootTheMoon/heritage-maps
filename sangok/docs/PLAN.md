# JSN_Sangok → OVERDARE 반입 계획

2026-08-18 착수. 사용자 결정: **식생 LOD 22/35% (4,715v)**, **충돌은 엔진 Part**.

## 왜 인스턴스 방식인가

이 씬은 **2,398 오브젝트 / 유니크 메시 15개**다. 전부 구워서 정적으로 내면
4,700만 삼각형이 나온다. 시부야에서 검증된 대로 `mesh.users`로 갈라야 한다.

| | | |
|---|---:|---|
| STATIC (`users == 1`) | 4 메시 | 지형·계류·지류·석단. 월드 좌표 그대로 내보내면 임포터가 (0,0,0)에 떨궈 맵이 자동 조립된다 |
| INSTANCED (`users > 1`) | 11 메시 | 마스터를 자기 피벗에 재중심 + `placements.csv` + 스포너 Lua |

## 오버데어 하드 규칙 (docs.overdare.com)

- 메시당 **≤30,000 tris** — 파일 총합이 아니라 메시 기준. 안전하게 28k로 잡는다
- 파일 **≤250 MB**
- 텍스처 **≤15 MB, 권장 512**(4K/8K는 임포터를 죽인다)
- `.fbx`/`.obj`만
- **UCX 콜라이더는 오버데어에서 죽은 경로다** — Studio가 크래시한다. 엔진 Part를 쓴다
- 성능 권장: 프롭당 ~700 verts, 화면당 ~70,000 verts. **삼각형이 아니라 정점을 센다**
- 임포트 단위는 파일도 오브젝트도 아닌 **머티리얼**이다 → 텍스처 수를 줄이는 게 곧 발행 에셋 수를 줄이는 것

## 단계

### 1. 텍스처 준비 (PIL, 디스크에서)
`img.scale()`은 헤드리스에서 못 쓴다(지연 로딩 + 팩 이미지 문제). **PIL로 미리 굽는다.**
- NM/RN/AO 버리고 **BC만** 남긴다 (여분 맵은 표면을 오염시킨다)
- OP가 있으면 BC의 알파 채널로 합성 → RGBA 한 장
- 512×512로 리샘플
- 58장 / 735 MB → **13장 / 약 4 MB**

### 2. 마스터 감량 (11개)
- **식생은 카드 섬 단위로 솎는다.** collapse는 알파 카드를 파편으로 부순다(검증함)
  - 곰솔 잎 22% / 수피 35% → 4,715v / 4,900t
  - 억새·쑥도 같은 방식
- **자연 암석은 collapse 가능** (창덕궁의 상자형 구조물과 다른 경우)
  - RockA~F 118k~311k → ≤28k
  - RockMass 1,797,148 → ≤28k
- 자갈 20t는 그대로

### 3. 지형 (STATIC, 가장 까다로움)
지형 재질은 **정점컬러 4방 블렌드 + BOX 투영**이라 타일 텍스처 한 장으로 못 낸다.
`bpy.ops.object.bake` 대신 **`blend_at()`을 파이썬에서 평가해 PIL로 굽는다** —
텍셀마다 월드 좌표를 구해 마스크를 계산하고 4장을 합성한다. 결정적이고 재현 가능하다.
- 233,920 tris → 28k 이하 타일로 분할 (약 9~10장)
- 타일마다 베이크한 512 텍스처 1장

### 4. 배치 테이블
`placements.csv` — 2,387 인스턴스.
단위: `X = x*100, Y = z*100, Z = y*100`, `yaw_deg = -degrees(rot_z)`.
**yaw 부호는 엔진 밖에서 검증 불가** — 반입 후 바위 하나로 확인할 것.

### 5. 충돌 (엔진 Part)
UCX 금지. 지형은 적응형 격자 박스, 바위는 회전 박스(축정렬 박스는 45° 회전체를
40% 이상 부풀린다). `overdare_create_instances`용 CSV로 낸다. 발행 에셋 0개.

### 6. 검증
**쓴 FBX를 다시 임포트해서 측정한다.** 이게 가장 강한 검증이다.
bbox ±5%, 메시당 tris, 텍스처 해상도, 파일 크기.

## 함정 (전부 실제로 당한 것)

- 헤드리스에서 `bpy.ops.mesh.separate`는 실패하지 않고 **무한정 돈다**. 손으로 서브메시를 만들 것
- `img.copy()` + `img.scale()`은 헤드리스에서 못 쓴다. PIL로 미리
- `img.has_data`는 유효성 판단 기준이 아니다 (정상 파일에도 False)
- FBX는 **Principled Base Color에 물린 이미지 하나만** 내보낸다
- 배치 좌표는 **월드**로 (STATIC), 마스터는 **자기 피벗 재중심**으로
- 파일당 오브젝트 하나 — 임포터가 오브젝트마다 월드 에셋을 발행하고 누수시킨다
