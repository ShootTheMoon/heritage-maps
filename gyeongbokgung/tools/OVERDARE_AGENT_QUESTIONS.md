# OVERDARE Studio 에이전트에게 — 좌표 규약 확인 요청

Blender 로 만든 경복궁을 이 레벨(`onlyoneshot`)에 옮기는 중입니다.
FBX 는 이미 임포트돼 있고 MeshPart 176개가 배치돼 있습니다.
**아래 두 가지만 확인해 주세요. 인스턴스를 추가·수정·삭제하지 말아 주세요**
(다른 도구가 이 레벨에 쓰기 작업 중이라 동시 편집하면 유실됩니다).

---

## 배경 — 이미 측정으로 확정한 것

| 항목 | 값 | 확인 방법 |
|---|---|---|
| 단위 | Blender 1 m = OVERDARE 100 units | 1m 큐브의 `UnitExtent` 가 ±50 |
| 축 순열 | Blender (x, y, z) → OVERDARE (**X, Z, Y**) | Blender 에서 X로 4m, Y로 6m, Z로 8m 인 막대 3개를 임포트했더니 `UnitExtent` 가 각각 X=200, **Z**=300, **Y**=400 으로 나옴 |
| 재중심화 | 임포터가 각 메시를 **개별적으로** 재중심화한다 | 파일 원점에서 10/20/30 m 떨어뜨린 메시 5개를 전부 같은 CFrame 에 놨더니 한 점에 겹침 |

Blender 쪽 좌표계: **+X = 동, +Y = 북, +Z = 위**, 미터 단위.

현재 쓰고 있는 변환식 (Scale = 0.6, 궁궐 지면을 Y=5000 에 놓음):

```
X = blender_x * 100 * 0.6
Y = blender_z * 100 * 0.6 + 5000
Z = blender_y * 100 * 0.6 * (-1)      ← 이 부호가 질문 1
Size = (|blender_size_x|, |blender_size_z|, |blender_size_y|) * 100 * 0.6
Orientation = (0, 0, 0)               ← 회전은 메시에 구워 넣었음
```

---

## 질문 1 — Z 부호가 맞습니까?

OVERDARE 문서에 **−Z 가 forward** 라고 되어 있어서, Blender 의 **+Y(북)** 를
**−Z** 로 보냈습니다. 즉 `Z = -blender_y * 100 * scale`.

이게 틀렸다면 궁궐 전체가 앞뒤로 뒤집힙니다(미러). 확인 방법:

레벨의 `Workspace/Gyeongbokgung` 안에서 이름으로 찾을 수 있습니다.

| 인스턴스 이름 | 무엇인가 | 현재 Z | 실제로 있어야 할 곳 |
|---|---|---|---|
| `GJM_*` (예: `GJM_LO_COL_...`) | **근정문** — 정문. 2층 문루 | **+4,680** | 궁궐의 **남쪽 정면**. 그 앞으로 넓은 마당(조정)이 있어야 함 |
| `SJJ_*` (예: `SJJ_COL_...`) | **사정전** — 뒤쪽 편전 | **−4,438** | 궁궐 **가장 안쪽(북쪽)** |
| `GJJ_*` | **근정전** — 중앙 정전. 제일 크고 2층 지붕 | **≈ 0** | 한가운데 |

**질문: 뷰포트에서 봤을 때, 2층 문루(근정문, Z=+4680)와 넓은 빈 마당이
같은 쪽에 있고, 가장 작고 단층인 사정전(Z=−4438)이 그 반대편 끝에 있습니까?**

- 그렇다 → 부호 맞음
- 아니라면(문루가 사정전 쪽에 붙어 있거나 순서가 반대라면) → **부호를 뒤집어야 함**

## 질문 2 — 임포트된 메시는 CFrame 을 어디에 맞춥니까?

MeshPart 를 만들 때 `CFrame.Position` 에 **그 메시의 바운딩박스 중심**을 넣고,
`Size` 에 **바운딩박스 크기**를 넣었습니다. 즉 메시가
`CFrame ± Size/2` 범위를 정확히 채운다고 가정했습니다.

**질문: 실제로 그렇습니까?** 아무 MeshPart 하나(예: `GJJ_WOLDAE_LO_...` 같은
큰 석축)를 선택해서, **선택 상자(gizmo)의 중심이 실제 메시 형상의 중심과
일치하는지** 봐 주세요.

- 일치 → 가정 맞음
- 메시가 상자 밖으로 삐져나오거나 한쪽으로 쏠려 있다면 → **어디로 얼마나
  치우쳐 있는지** 알려주세요 (예: "형상이 상자보다 +Y로 절반쯤 올라가 있다")
